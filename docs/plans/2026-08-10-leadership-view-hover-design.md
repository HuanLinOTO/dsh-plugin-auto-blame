# Leadership View Hover Design

Rename the suggestion label from "毒舌跟进" to "领导视野". Keep each suggestion button compact and stationary with single-line truncation. On pointer hover or keyboard focus, show the full suggestion in an absolutely positioned card above the button. The card does not participate in flex layout and ignores pointer events, so it cannot move the hover target or displace adjacent suggestions. Submission behavior and projection data remain unchanged.
